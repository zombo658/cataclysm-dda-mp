# Сетевой протокол (версия 2)

TCP, порт 7777. Каждое сообщение — один JSON-объект в одной строке (NDJSON),
строки разделены `\n`. Сервер — процесс игры хоста. Клиент — сама игра (Мультиплеер → Join game,
`src/mp/client_ui.cpp`) или `tools/mp/client.py`.
Одновременно подключён только один клиент; второму сервер отвечает `error` и
закрывает соединение.

Команды идут первому RC-NPC в пузыре реальности хоста (`mp::network_npc()`).

## Клиент → сервер

Поле `cmd` обязательно.

| Сообщение | Что делает |
|---|---|
| `{"cmd":"move","dir":"n"}` | шаг на соседнюю клетку; враждебное существо на ней атакуется |
| `{"cmd":"attack","dir":"e"}` | удар по существу на соседней клетке |
| `{"cmd":"wait"}` | пропустить ход |
| `{"cmd":"pickup"}` | подобрать всё с клетки под собой |
| `{"cmd":"status"}` | запросить статус, в очередь не ставится |

`dir`: `n`, `ne`, `e`, `se`, `s`, `sw`, `w`, `nw` (север — вверх по карте).

Команды ставятся в очередь и выполняются, когда у персонажа есть ходы.
Можно слать несколько команд подряд.

## Сервер → клиент

Поле `type` есть всегда.

| `type` | Когда | Поля |
|---|---|---|
| `welcome` | сразу после подключения | `version`, `npc` (имя персонажа, если он есть) |
| `log` | перед `your_turn`, если в логе хоста появились новые сообщения | `lines` (массив строк) |
| `view` | перед каждым `your_turn` | `radius`, `rows`, `palette` (см. ниже) |
| `your_turn` | мир остановился и ждёт команду | `status` |
| `ok` | команда принята в очередь | `cmd` |
| `rejected` | команда из очереди не выполнима (стена, нечего подбирать…) | `reason` |
| `status` | ответ на `status` | `status` |
| `error` | неразобранная строка, неизвестная команда, нет персонажа | `message` |

`status`: `name`, `hp`, `hp_max` (сумма по частям тела), `stamina`,
`stamina_max`, `hunger`, `thirst`, `sleepiness`, `pain`, `moves`,
`pos` (`[x, y, z]`, абсолютные координаты клеток карты).

`view` — то, что видит персонаж, квадрат `2*radius+1` клеток, персонаж в
центре. `rows` — строки сверху вниз (север сверху), каждая — массив клеток
`[символ, индекс_цвета]`. Символ — строка UTF-8, `" "` — клетка не видна.
`palette` — имена цветов CDDA (`c_white`, `c_light_green`…), индекс цвета
указывает в этот массив. Что показано в клетке: существо (если видно),
иначе часть транспорта, иначе верхний предмет, иначе мебель, иначе местность.

`log` — новые сообщения лога хоста (служебные «Waiting for…» отфильтрованы).
Пока это общий лог хоста, а не лог второго персонажа.

## Синхронизация

* Пока у RC-NPC есть ходы и пустая очередь, время в игре стоит, сервер шлёт
  `your_turn`. Хост в это время может только смотреть (карта, осмотр, сообщения).
* Если сервер запущен, а клиента нет, персонаж стоит на месте (пропускает
  ходы) и игра идёт дальше. Это временное решение открытого вопроса про
  отключение клиента.
* Если сервер не запущен, работает hot-seat: RC-NPC управляется клавишами
  хоста (см. `CLAUDE.md`, этап 2).

## Пример

```
<- {"type":"welcome","version":1,"npc":"Lewis Bright"}
<- {"type":"your_turn","status":{"name":"Lewis Bright","hp":876,...,"moves":100,"pos":[-972,83,0]}}
-> {"cmd":"move","dir":"w"}
<- {"type":"ok","cmd":"move"}
-> {"cmd":"attack","dir":"n"}
<- {"type":"ok","cmd":"attack"}
<- {"type":"rejected","reason":"nothing to attack there"}
```
