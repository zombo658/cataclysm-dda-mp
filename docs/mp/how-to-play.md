# Как играть вдвоём (Windows)

Состояние на этап 3: второй игрок управляет своим персонажем по сети, но
картинку пока видит только у хоста. Смотреть её можно через демонстрацию
экрана (Discord, Parsec и т. п.).

## Хост

### 1. Скачать игру

GitHub → репозиторий → **Actions** → **MP: Windows build** → последний
успешный запуск → внизу **Artifacts** → `cdda-mp-windows-x64`.
Внутри zip-архив: распаковать в любую папку, запускать `cataclysm-tiles.exe`.
В папке `mp` лежат клиент для второго игрока и эта инструкция.

Нужен вход в GitHub, артефакт хранится 14 дней. Если устарел — Actions →
MP: Windows build → **Run workflow** (сборка идёт 1–2 часа).

### 2. Включить debug-меню

Пункты мультиплеера пока сидят в debug-меню, а у него нет клавиши по
умолчанию (без клавиши меню показывает только «Info…»).

В игре: `?` (клавиши) → найти **Debug menu** → назначить клавишу, например `` ` ``.

Debug-меню отключает достижения в этом мире — это нормально.

### 3. Выбрать персонажа второму игроку

1. Загрузить или создать мир. Рядом должен быть NPC (в стартовом убежище он
   обычно есть).
2. Debug-меню → **Player…** → **Multiplayer: remote NPC** → `t` → выбрать NPC.
   Он становится вашим последователем и перестаёт думать сам.

Флаг сохраняется вместе с миром.

### 4. Запустить сервер

Debug-меню → Player… → Multiplayer: remote NPC → `s` (**Start the server**).
Сервер слушает TCP-порт **7777**. При первом запуске Windows спросит про
брандмауэр — разрешить для частных сетей.

Сервер нужно запускать заново после каждой загрузки игры.

Пока сервер запущен, а второй игрок не подключился, его персонаж просто
стоит, а игра идёт. Когда подключится, игра будет ждать его хода.

### 5. Как дать второму игроку подключиться

* **Одна локальная сеть**: второму игроку нужен ваш локальный IP
  (`ipconfig` → IPv4-адрес, вида `192.168.x.x`).
* **Через интернет**: проще всего виртуальная сеть — Radmin VPN, ZeroTier,
  Tailscale. Оба ставят одну программу, заходят в одну сеть и используют
  выданный ею IP хоста. Другой вариант — пробросить TCP-порт 7777 на роутере.

## Второй игрок

1. Установить Python 3 с python.org (галочка «Add python.exe to PATH»).
2. Взять у хоста папку `mp` с `client.py`.
3. В этой папке: `python client.py --host <IP хоста>`.

Клавиши (окно клиента должно быть активно):

| Клавиша | Действие |
|---|---|
| `h j k l y u b n`, стрелки, цифры 1–9 | шаг (в сторону врага — удар) |
| `a`, потом направление | атака |
| `.` или `5` | ждать ход |
| `g` | подобрать всё под собой |
| `s` | статус |
| `q` | выйти |

Клиент пишет `YOUR TURN` и статус персонажа, когда игра ждёт вашего хода.
Пока вы думаете, время у хоста стоит, и он может только смотреть.

## Если что-то не работает

* «Can't start the multiplayer server on port 7777» — порт занят другой
  программой (или второй копией игры).
* Клиент не подключается — проверить IP, брандмауэр Windows у хоста, что
  сервер запущен (пункт меню показывает **Stop the server**).
* «another player is already connected» — одновременно может играть только
  один второй игрок.
