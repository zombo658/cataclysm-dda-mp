# Как играть вдвоём (Windows)

Оба игрока запускают одну и ту же сборку игры. Хост играет как обычно, второй
игрок управляет своим персонажем и видит вокруг него карту тайлами (или
символами, если графика в настройках выключена). Время второго игрока не
считается: его действия выполняются сразу, хост его не ждёт.

## Скачать игру (оба игрока)

GitHub → репозиторий → **Actions** → **MP: Windows build** → последний
успешный запуск → внизу **Artifacts** → `cdda-mp-windows-x64`.
Внутри zip-архив: распаковать в любую папку, запускать `cataclysm-tiles.exe`.

Нужен вход в GitHub, артефакт хранится 14 дней. Если устарел — Actions →
MP: Windows build → **Run workflow** (сборка идёт 1–2 часа).

Версии у обоих должны совпадать (клиент предупредит, если нет).

## Хост

1. Если мира ещё нет — сначала обычная **New Game**, сохраниться и выйти.
2. Главное меню → вкладка **Multiplayer** → **Host game** → выбрать мир и
   сохранение.
3. Игра загрузится, запустит сервер на TCP-порту **7777** и спросит, кем будет
   играть второй игрок: кем-то из NPC рядом или **A new character** (новый
   случайный персонаж появится рядом с вами). Он станет вашим союзником.
4. Windows может спросить про брандмауэр — разрешить для частных сетей.

Выбор сохраняется вместе с миром: в следующий раз Host game сразу запустит
сервер с тем же персонажем.

Пока второй игрок не подключён, его персонаж просто стоит, а игра идёт.
Когда он подключён и у него есть ход, время останавливается: вы можете
смотреть карту и сообщения, но не действовать, пока он не походит.

### Как дать второму игроку подключиться

* **Одна локальная сеть**: ваш локальный IP (`ipconfig` → IPv4-адрес, вида
  `192.168.x.x`).
* **Через интернет**: проще всего виртуальная сеть — Radmin VPN, ZeroTier,
  Tailscale. Оба ставят одну программу, заходят в одну сеть и используют
  выданный ею IP хоста. Другой вариант — пробросить TCP-порт 7777 на роутере.

## Второй игрок

Главное меню → **Multiplayer** → **Join game** → ввести IP хоста (или
`IP:порт`, если порт не 7777). Мир загружать не нужно.

Сверху статус персонажа, в центре — карта вокруг него, внизу — лог.
При подключении игра загружает данные модов мира хоста (несколько секунд),
чтобы рисовать тайлы. Звуки хоста слышны и вам (звуковой пакет CC-Sounds
есть в сборке; выбрать его можно в Options → Sound, если стоит другой).

Экран устроен как у хоста: карта слева, справа боковая панель (части тела,
характеристики, голод/жажда/усталость, место, погода, время, оружие, кто
виден рядом) и лог. Клавиши — те же, что в обычной игре, с вашими
переназначениями:

| Действие игры (клавиша по умолчанию) | Что делает |
|---|---|
| движение (стрелки, цифры, `hjklyubn`) | шаг; в сторону врага — удар |
| ждать (`.`, `5`) | пропустить ход |
| подобрать (`g`, `,`) | подобрать всё под собой |
| инвентарь (`i`) | список вещей → действие |
| взять в руки (`w`), надеть (`W`), снять (`T`), съесть (`E`), выбросить (`d`) | список подходящих вещей → сразу действие |
| сообщения (`P`) | весь лог |
| главное меню (Esc) | выйти |

Остальные действия пока пишут в лог «not available to the second player yet».

Есть и отдельный клиент без игры: `mp/client.py` (нужен Python 3),
`python client.py --host <IP хоста>` — без карты, только команды и статус.

## Если что-то не работает

* «Can't start the multiplayer server on port 7777» — порт занят другой
  программой (или второй копией игры).
* Клиент не подключается — проверить IP, брандмауэр Windows у хоста, что
  сервер запущен (пункт меню показывает **Stop the server**).
* «another player is already connected» — одновременно может играть только
  один второй игрок.
